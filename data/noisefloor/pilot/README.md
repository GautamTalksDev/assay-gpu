# noisefloor-pilot-v1

This directory is **not** a characterization. Lookup ignores every path
whose parts include `pilot`, even if a file is named `run-*.json`.

`assay characterize --pilot` writes `pilot-<utc>-<gpu>.json` here.
`min_samples` in `methodology-v1.json` is unchanged. p99.999 is
UNJUSTIFIED until a pilot report is read.
