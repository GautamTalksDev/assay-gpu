# Support

This project is a skeleton. There is no application logic and no production
support channel yet.

## Before asking for help

1. Read the Kill Tests in `README.md`. If a kill test has failed, the
   project has stopped; do not expect feature work.
2. Read `CONTRIBUTING.md` if you intend to send a patch.
3. Read `SECURITY.md` for vulnerability reports.

## Questions

Open a GitHub issue for:

- defects in packaging, CI, or documentation
- questions about measured data in `data/noisefloor/`
- proposals that include a path to unit tests and a measured threshold

Do not open issues that ask for heuristic detectors, LLM judges, or
undocumented numerical cutoffs.

## Conduct

Participation is governed by `CODE_OF_CONDUCT.md`.
